# isba-biostatspharma.github.io

Website of the ISBA Section on Biostatistics and Pharmaceutical Statistics:
https://isba-biostatspharma.github.io

The site is authored with [Quarto](https://quarto.org) in **`index.qmd`** —
see [EDITING.md](EDITING.md) for the editing guide.

On every push to `master`, a GitHub Action (`.github/workflows/publish.yml`)
renders the site and deploys it to GitHub Pages. There is no `index.html` in
this repository — it is generated by the Action. Edit `index.qmd` instead.
